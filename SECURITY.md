# 🛡️ Security Policy & Incident Reporting

## Reporting a Vulnerability

If you discover a security vulnerability in Infra Monitoring Dashboard, please email `security@inframonitor.internal` with reproduction details. We respond within 24 hours.

## Security Controls

- **SAST & Secret Audits**: CodeQL and Gitleaks scanning on every commit.
- **Incident Routing**: Integrated with PagerDuty Events API v2 and Wazuh SIEM detection rules.
