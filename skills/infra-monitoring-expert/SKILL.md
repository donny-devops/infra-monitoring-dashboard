# Infrastructure Monitoring & Anomaly Detection Expert

Use this skill when auditing server infrastructure, reviewing anomaly alerts, querying threat intelligence feeds, or configuring Wazuh/PagerDuty integrations.

## Core Capabilities

1. **Host Diagnostics**: Real-time metrics analysis across CPU, Memory, Disk, and Network I/O.
2. **AI Anomaly Detection**: Evaluate predictive maintenance signals and automated health insights.
3. **Security Integrations**:
   - PagerDuty incident payload generation.
   - Wazuh SIEM XML rules generator.
   - Nmap scan parsing and host discovery.
